# MeduzaVPN 1.2.43 (250) — Windows update

Windows graphical application update. Other applications, CLI packages and store submissions are unchanged.

## Changes

- ULTRA startup no longer blocks status updates while waiting for an unreachable or slow server. The pending attempt continues to report “connecting”.
- Canceling a pending ULTRA connection no longer waits for the startup timeout. A canceled attempt is cleaned up before the next attempt can use the tunnel adapter.
- Startup timeouts include a bounded network/SSH failure category for diagnostics without exposing peer-supplied text or credentials.

This release fixes a reproduced Windows startup/status/cancellation defect. It does not claim to make blocked server addresses reachable or resolve every ISP-specific timeout.

- Signed installer and installed application/ULTRA DLL verified with valid IPFB LLC Authenticode signatures. Installed application reports `1.2.43+250`; installed ULTRA DLL matches the release package.
- 33 Flutter regression tests and Go lifecycle/Windows policy race tests passed.

The network checks exercise the installed ULTRA DLL through a test harness. They are not an exhaustive manual walkthrough of every protocol or a guarantee of reachability from every customer network.
