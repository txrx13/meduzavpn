# MeduzaVPN 1.2.43 (244)

**Android, macOS DMG and macOS CLI: 1.2.43 (244).** Apple and Google store builds 244 have been submitted for review. Windows GUI remains **1.2.42 (243)**. Linux GUI/CLI, Windows CLI, router and OpenWrt packages, and the apt/dnf repositories remain **1.2.42 (242)** while their builds are pending. The download table and signed manifest identify the exact version and source of every file.

## What changed

- Sign in on Android TV by scanning a QR code with your phone; the TV signs in after confirmation.
- Reopen unfinished orders with the selected locations and purchase settings preserved.
- Updated payment-method ordering for customers in Iran.
- Includes the Windows ULTRA route-capture and leak-detection improvements released in build 243.
- Retains the compact server list, on-demand configuration cache, connection-state fixes and ULTRA stability improvements from build 242.
- Apple and Android native VPN components rebuilt from the published main revision.

## Install from our apt / dnf repository (recommended)

The GUI is available for **x86-64**. The CLI and VPN service are available for **x86-64 and ARM64**. The repositories install dependencies and support normal system updates.

<details open>
<summary><b>Debian · Ubuntu</b></summary>

```bash
curl -fsSL https://meduzavpn-builds.fra1.digitaloceanspaces.com/repo/meduzavpn-archive-keyring.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/meduzavpn.gpg

echo "deb [signed-by=/usr/share/keyrings/meduzavpn.gpg] https://meduzavpn-builds.fra1.digitaloceanspaces.com/repo/deb stable main" \
  | sudo tee /etc/apt/sources.list.d/meduzavpn.list

sudo apt update
sudo apt install meduzavpn-desktop   # the app (GUI) — pulls in the service
sudo apt install meduzavpn           # a server: command line and service only

# Already installed? Update the packages you use:
sudo apt install --only-upgrade meduzavpn-desktop meduzavpn  # GUI + service
# CLI/service only: sudo apt install --only-upgrade meduzavpn
```
</details>

<details open>
<summary><b>Fedora · CentOS · RHEL</b></summary>

```bash
sudo rpm --import https://meduzavpn-builds.fra1.digitaloceanspaces.com/repo/meduzavpn-archive-keyring.asc

sudo tee /etc/yum.repos.d/meduzavpn.repo >/dev/null <<'REPO'
[meduzavpn]
name=MeduzaVPN
baseurl=https://meduzavpn-builds.fra1.digitaloceanspaces.com/repo/rpm
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://meduzavpn-builds.fra1.digitaloceanspaces.com/repo/meduzavpn-archive-keyring.asc
REPO

sudo dnf install meduzavpn-desktop   # the app (GUI)
sudo dnf install meduzavpn           # command line and service only

# Already installed? Update the packages you use:
sudo dnf upgrade --refresh meduzavpn-desktop meduzavpn      # GUI + service
# CLI/service only: sudo dnf upgrade --refresh meduzavpn
```
</details>


The service is not enabled automatically. Start it when ready with `sudo systemctl enable --now meduzavpnd`.
