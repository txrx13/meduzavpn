## Installation

Install **either** `meduzavpn-desktop` for the graphical application (daemon included) **or** `meduzavpn` for a headless CLI/service installation. Use the [signed apt/dnf instructions](https://github.com/txrx13/meduzavpn/blob/main/README.md#install-on-linux). On RHEL, CentOS Stream, Rocky or Alma Linux 9 both packages install without EPEL; enabling EPEL only adds the tray icon library for `meduzavpn-desktop`. Windows: [meduzavpn.com/download/windows](https://meduzavpn.com/download/windows). Android: [meduzavpn.com/download/android](https://meduzavpn.com/download/android). macOS: [meduzavpn.com/download/macos](https://meduzavpn.com/download/macos).
