# MeduzaVPN 1.2.36 (230)

Source: private MeduzaVPN repository main, `7dba26be958e3b9ca744501173596d96cf2bc086`.

In the mobile/desktop apps and website account, stopped VPNs that can still be restored remain visible with their identity, billing date and restoration deadline. Renewal notifications target the correct service and offer a payment action where supported. The account page and app show payment confirmation and server restoration separately.

The release includes notification inbox refresh, stable cached server lists, ULTRA carrier recovery, queued-packet buffers sized to reduce memory use while preserving four iOS carriers, and live Apple tunnel diagnostics with cross-process clearing. The Mac App Store build excludes Apple Pay / PassKit; the website DMG retains its website payment integration.

Native Apple, Android, Windows and router components are rebuilt from the release source. Apple TV uses its separate 1.0.0 (230) beta version.
