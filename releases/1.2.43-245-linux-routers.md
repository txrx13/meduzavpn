# MeduzaVPN 1.2.43 (245) — Linux and routers

Linux desktop, Linux CLI/service, router archives and OpenWrt packages are updated from build 242 to build 245. This completes the Linux/router portion of the release from the current published application main revision. Windows is released separately; Android and macOS downloads remain build 244.

## Included packages

- Linux graphical application for x86-64, as DEB and RPM.
- Linux command-line client and VPN service for x86-64 and ARM64, as DEB, RPM and tar.gz.
- Static router binaries for MIPS, MIPS little-endian, ARMv7 and ARM64.
- OpenWrt packages for x86/64, MediaTek Filogic and MT7621, plus the LuCI interface.
- Updated signed apt and dnf repository indexes.

The Linux application includes unfinished-order recovery, checkout improvements, and a clear explanation when a VPN-settings QR is scanned on the sign-in screen. The VPN components include the accumulated connection, credential-renewal and stability changes since build 242.

## Install or update

See the [signed apt/dnf installation instructions](../README.md#install-on-linux). Existing users can update the installed packages normally:

```bash
sudo apt update
sudo apt install --only-upgrade meduzavpn-desktop meduzavpn
# Or on RPM-based systems:
sudo dnf upgrade --refresh meduzavpn-desktop meduzavpn
```

For a CLI-only installation, update only `meduzavpn`. Installation does not start the VPN service automatically.
