# MeduzaVPN 1.2.46 (265)

Every direct download is updated to build 265, all from the same published application main revision: Android (APK from the website), Windows (installer and command line), macOS (DMG and command line), Linux (packages, archives and the apt/dnf repositories), routers and OpenWrt. Before publication, the Android, Windows and Linux builds connected in every protocol mode on a test bench. The same build is in TestFlight for iOS and macOS, is waiting for App Store review on iOS, and was sent to Google Play production review.

## Changes since 263

- **The free trial is explained with dates** before you confirm it: today is free, a reminder email a day before it ends, and the exact day of the first charge (in the app and on the website).
- **Protocols and ports:** choose your own ports for the supported protocols in a VPN's settings.
- **Battery saver for MeduzaVPN ULTRA/2** (off by default; turn it on in Settings), and ULTRA/2 keeps a steady connection when a network path is parked or a carrier is lost.
- **"Fix connection"** checks your own internet around the VPN, waits for the server after a change instead of changing it again, says "no problems found" when everything works, and the red "VPN is not connecting" card clears as soon as you connect.
- **Accounts created with Google or Apple sign-in** can be deleted from the app.
- **Payment methods follow the store country** where the store cannot charge, so those customers see a checkout that works for them.
- **Diagnostics:** connection events and on-device debug reports help support see what happened on your device (no traffic contents, no personal data).

## Installation

Install **either** `meduzavpn-desktop` for the graphical application (daemon included) **or** `meduzavpn` for a headless CLI/service installation. Use the [signed apt/dnf instructions](../README.md#install-on-linux). Windows: [meduzavpn.com/download/windows](https://meduzavpn.com/download/windows). Android: [meduzavpn.com/download/android](https://meduzavpn.com/download/android). macOS: [meduzavpn.com/download/macos](https://meduzavpn.com/download/macos).

## Verification and limits

- **Source:** every artefact was built from `958f84f5`, checked on main before and after each build step. Version strings inside the artefacts read 1.2.46 / 265.
- **Connection test gate (before publication):** on a test bench, with lab accounts only, the published Android APK, Windows installer and Linux package connected in all three modes (hybrid, ULTRA/2 only, ULTRA/1 only). Each run checked the exit IP, DNS (20/20 lookups), a download, and disconnect/reconnect. The mode was confirmed by the protocol in the journal and by the carrier count.
- **"Fix connection" card:** on Android and Windows, with the location blocked, the "VPN is not connecting" card with "Fix" appeared after the first failure. It cleared as soon as the connection came back.
- **Android:** APK signed with the release certificate (CN=Meduza VPN), versionCode 265 / versionName 1.2.46. The ULTRA engine is present for arm64-v8a, armeabi-v7a and x86_64, and the app carries the ULTRA signing root. It upgrades over 264 and starts cleanly.
- **Windows:** the installer, the app and the ULTRA engine are Authenticode-signed (IPFB LLC, timestamped). A silent install in the build VM installs 1.2.46+265 with valid signatures and the app starts. An upgrade from 264 succeeds. The Windows command-line archive is signed and reports 1.2.46+265.
- **Linux:** the ULTRA signing roots are in `meduzavpnd`. Installed from the local files on Ubuntu 24.04, Debian 13 and CentOS Stream 9, the GUI starts. The repository's systemd end-to-end test passed 106 checks and failed 14, the same "after upgrade to core" harness expectations as in earlier releases. RPMs and repository metadata are signed. Installs from the public apt/dnf repositories were checked on Ubuntu 24.04, Debian 12, CentOS Stream 9 and Fedora 41.
- **Routers / OpenWrt:** four static daemon archives report 1.2.46 and carry the production ULTRA roots. The OpenWrt packages pass the install test in an OpenWrt userland.
- **macOS:** the DMG and the universal command-line archive are built, signed, notarized and stapled on Apple hardware from the same revision.
